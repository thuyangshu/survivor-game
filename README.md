# 暗夜幸存者

网页肉鸽割草小游戏。角色自动攻击，你只管走位，升级时三选一，活过 10 分钟即胜利。

**在线玩：** https://thuyangshu.github.io/survivor-game/

- 电脑：WASD / 方向键移动，Esc 暂停，升级时按 1/2/3 快选
- 手机：按住屏幕任意位置拖动
- 声音：首次点击后开始播放，⚙️ 设置里可换背景音乐、调音量

本仓库只包含打包后的单文件 `index.html`（由源码项目的 `build.mjs` 生成，请勿手改）。
第三方库：Phaser 3.90、nipplejs 0.10.2、ZzFX 1.3，均为 MIT 许可。
